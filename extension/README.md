# FluentFox Extension

Transparent, immersive website styles for stock Firefox.

This extension is a rebranded fork of [Zen Internet](https://github.com/sameerasw/zeninternet)
(MIT), which builds on [Transparent Zen](https://github.com/frostybiscuit/transparent-zen)
(MIT). Site CSS is fetched from the upstream
[my-internet](https://github.com/sameerasw/my-internet) styles repository.

See the root [README](../README.md) for full install instructions (extension + browser chrome theme).

## Development

```bash
npx web-ext lint
npx web-ext run
```

Temporary install: Firefox → `about:debugging` → This Firefox → Load Temporary Add-on → select `manifest.json`.
